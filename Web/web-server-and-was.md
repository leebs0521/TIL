# 1. 웹 서버와 웹 어플리케이션 서버

- 웹 서버와 웹 어플리케이션 서버는 둘 다 웹 서비스를 제공하지만, 그 역할과 기능에 차이가 있다.

## 1.1. 웹 서버(Web Server)

- 기능:
    - **정적 컨텐츠 제공**:
        - 웹 서버는 HTML, CSS, JavaScript, 이미지 등 정적 파일을 클라이언트(웹 브라우저)에게 제공
    - **요청 처리**:
        - HTTP 요청을 수신하고, 해당 요청에 대해 적절한 파일 반환
- 작동 방식:
    - **파일 시스템 접근**:
        - 웹서버는 주로 파일 시스템에서 파일을 직접 제공하며, 요청된 파일의 경로에 따라 응답을 생성
    - **간단한 요청 처리**:
        - 요청된 파일이 존재하지 않으면 404 오류 반환, 서버 설정에 따라 다른 응답을 반환할 수도 있다.
- 예시
    - Apache HTTP Server
    - Nginx

## 1.2. 웹 어플리케이션 서버(Web Application Server)

- 기능:
    - **동적 컨텐츠 생성**:
        - 웹 어플리케이션 서버는 동적은 웹 어플리케이션을 처리 데이터베이스와 상호작용하고, 비지니스 로직을 처리하며, 동적으로 컨텐츠를 생성
    - **어플리케이션 로직**:
        - 복잡한 비지니스 로직을 처리하고, 사용자의 요청에 따라 다양한 작업을 수행
- 작동 방식:
    - **어플리케이션 처리**:
        - 클라이언트의 요청을 받아서 어플리케이션 로직을 처리하고, 결과를 생성하여 반환한다. 이 과정에서 데이터베이스와의 상호작용이 필요할 수도 있다.
    - **서버 내의 어플리케이션 호스팅**:
        - 웹 어플리케이션 서버는 JAVA, .NET, Python 등의 어플리케이션 서버 환경에서 어플리케이션 서버 환경에서 어플리케이션을 호스팅 할 수 있다.
- 예시:
    - Apache Tomcat
    - JBoss
    - Microsoft IIS

## 1.3. 웹 서버와 웹 어플리케이션 차이점

- 웹 서버는 주로 정적 콘텐츠를 클라이언트에 제공하는 반면, 웹 어플리케이션 서버는 동적 컨텐츠를 생성하고, 복잡한 비지니스 로직을 처리하며, 데이터베이스와 상호 작용한다.
- 웹 서버는 간단한 요청과 응답을 처리하며, 웹 어플리케이션은 어플리케이션 로직을 처리하여 결과를 반환한다.
- 웹 어플리케이션 서버는 웹 서버 기능을 포함 가능하며, 웹 서버와 연동되어 동적 콘텐츠를 제공하는 경우가 많다.
    - 정적 컨텐츠는 웹서버가 처리, 동적 컨텐츠는 웹 어플리케이션 서버가 처리하는 구조
